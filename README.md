## Deskripsi Repository

Isi repository mencakup kode program dan notebook yang digunakan untuk mempraktikkan konsep-konsep *Machine Learning* yang dipelajari. Setiap file menjadi bagian dari proses penerapan materi dari tahap pemahaman konsep hingga implementasi menggunakan Python.
